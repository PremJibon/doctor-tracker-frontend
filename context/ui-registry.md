## Extracted Patterns & Rules

1. **Neumorphic Soft Clinical Design**:
   - Single uniform base surface: `background` = `surface` = `#E6EBF1`.
   - Dual-layer shadows: `--shadow-raised` (`-6px -6px 14px #FFFFFF, 6px 6px 14px #C2CAD6`), `--shadow-inset`, `--shadow-pressed`.
   - Contrast safeguards: Every interactive control maintains a $\ge 3:1$ visible 1px border (`border-border`) and text maintains $\ge 4.5:1$ AA contrast (`#0F172A` on `#E6EBF1` gives 11.8:1).
   - Flat tables inside raised container: Tables stay flat without per-row neumorphism.
2. **Hydration-Safe State Persistence**:
   - Desktop sidebar collapsed/expanded state persists to `localStorage` safely using `useSyncExternalStore` without layout shifts or hydration flashes.
3. **Inclusive Date Filtering (Dhaka Timezone `UTC+6`)**:
   - Date range selections format dates as `YYYY-MM-DD` and backend queries handle boundary inclusivity (`23:59:59.999Z` for `to` parameter).
4. **WordPress-Style Bulk Operations**:
   - Checkbox header with indeterminate state, shift-click range selection, floating dock action bar, and safety caps (100 items).
   - 2-stage verification for entities with cascade dependencies (`DoctorBulkDeleteDialog`).
5. **URL State Synchronization**: Search, filters, sorting, date ranges, and pagination state live in URL search parameters to ensure shareability and back/forward navigation fidelity.
