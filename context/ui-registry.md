## Extracted Patterns & Rules

1. **URL State Synchronization**: Search, filters, sorting, and pagination state live in URL search parameters to ensure shareability and back/forward navigation fidelity. Mutations to URL parameters wrap in `startTransition` and pass `{ scroll: false }`.
2. **Dual-View Data Display**: All data tables implement `DataTable` providing semantic `<table>` rendering on viewport `>= 768px` (`md+`) and falling back to touch-optimized card stacks via `mobileCardRenderer` on `< 768px`.
3. **Mobile Drawer Pattern**: On mobile viewports, multi-input filter controls collapse into a trigger button opening a slide-over drawer with ESC key binding and background scroll lock (`overflow: hidden`).
4. **Form Inputs Touch Safety**: All inputs enforce `text-[16px]` on mobile to prevent iOS Safari auto-zoom, and buttons maintain `>= 40px` (ideally `44px`) minimum touch target dimensions.
5. **Clean Clinical Visual Language**:
   - Primary: `#0F766E` (Teal 700)
   - Secondary / Surface Muted: `#EEF2F6` (Slate 100)
   - Accent Pill / Icon Background: `#E6F6F4` (Teal 50)
   - Danger: `#EF4444` (Red 500)
   - Neutral Borders: `#E2E8F0` (Slate 200)
